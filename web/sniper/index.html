Sniper Range

3D-Ego-Sandbox: frei bewegen, Stahlplatten suchen, Entfernung messen, Kugelfall und Wind ausgleichen. Maßstab 1 Einheit = 1 Meter. Die Kugel ist kein Hitscan — Gravitation und Wind wirken über die Flugzeit.

Jetzt spielen Code auf GitHub

Browser-Slice

  • SR-500 — Repetierer, 500 m/s, Visier 5x / 10x / 20x
  • Elf Stahlplatten von 80 m bis 700 m
  • Wind pro Sitzung, Entfernungsmesser mit R

Nur Desktop

  • Adobe-Dörfer bei ~130 m, ~340 m und ~545 m
  • Laufende Trainingspuppen, Vorhalten bei ~400 m
  • AK-47 und Editor-Kamera

Steuerung

  • WASD, Maus, Shift, C
  • RMB Visier, LMB schießen, R Entfernung
  • Mausrad Zoom im Visier, Esc Pause

Desktop lokal starten

Miniconda-Umgebung sniper_range:

source ~/miniconda3/etc/profile.d/conda.sh
conda activate sniper_range
python main.py
Die Web-Version ist der erste spielbare Slice. Dorf, Puppen und die AK-47 bleiben in der Ursina-Desktop-Build.
